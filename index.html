    メニュー

    1. 対応サイトの一覧ページURL（カテゴリ・検索結果・ランキングなど）を入力欄に貼り付けます。
    2. 「ページ数」で読み込むページ数を選びます（初期値3。スクロールでさらに自動読み込みされます）。
    3. 必要なら「記事URLの正規表現」で対象を絞り込み、「読み込んで再生」を押します。

    動画は自動で抽出されて再生キューに追加され、順番に再生が始まります。

    対応サイト（プリセット）

    • Twitter/X動画まとめ：ToxicStream / おなりずむ / ポッカキット / 露出羞恥に魅せられて
    • twi-dl / ヌキストリーム / monsnode / monsnodes / twihub
    • その他：FC2ライブ（アダルト配信） / Spankbang

    主な操作

    • 1〜9：同時再生数を変更（10〜16は数値入力）　WASD：フォーカス移動
    • Space：再生/停止　B/N：前後の動画　Z/X：5秒シーク　C/V：30秒シーク
    • ↑/↓：音量　M：ミュート　F/G/H：再生速度（等速/2.5倍/10倍）
    • Shift併用で全画面に適用。「リンクをコピー」で再生状態をURL共有できます。

    注意

    • 埋め込み（iframe）型の動画はシーク・速度変更などの操作が効かない場合があります。その場合はセルをクリックすると埋め込みプレイヤーを直接操作できます。
    • DMM動画は各タイトルのサンプル動画（予告編）が対象です。本編は有料のため再生できません。

    このツールについて

    「動画サイト複数再生」は、ブログ記事や動画まとめサイトの一覧ページURLを入力するだけで、ページ内の記事から動画を自動で抽出し、連続再生や複数画面での同時再生ができる無料のブラウザツールです。FC2動画・DMM動画・xvideo-jp・openload・missav・Pornhub・TXXX・twihub・twi-dl・ヌキストリーム・monsnode・monsnodes・ToxicStream・おなりずむ・ポッカキット・露出羞恥に魅せられて など、複数の動画サイトに対応しています。キーボードだけで再生・一時停止・シーク・音量・再生速度の操作ができ、シャッフル再生やサムネイル付きの再生キュー、URLを共有して同じ再生状態を再現する機能も備えています。

    使い方は簡単です。対応サイトの一覧ページ（カテゴリ・検索結果・ランキングなど）のURLを入力欄に貼り付け、必要に応じてページ数と記事URLの絞り込み正規表現を指定して「読み込んで再生」を押すだけです。抽出された動画は自動で再生キューに追加され、再生が始まります。
